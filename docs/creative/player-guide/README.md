# KOCHIVO — دليل اللاعب

معاينة فيديو صامت مدتها **6:56**، بنسبة **9:16** ودقة **1080×1920**. 34 خطوة داخل 10 فصول، بكتابة مصرية على الشاشة ومن غير تعليق صوتي أو موسيقى.

## التشغيل

من جذر المشروع:

```text
node docs/creative/player-guide/server.mjs
```

افتح [معاينة الدليل](http://127.0.0.1:4319). تقدر تشغّل وتوقف، تحرّك شريط الوقت، ترجع أو تتقدم خطوة، أو تفتح فصل مباشرة.

زر **صدّر فيديو صامت** يسجّل المعاينة داخل المتصفح. سيب الصفحة مفتوحة وفي الواجهة مدة الفيديو. المتصفح يختار MP4 لو متاح أو WebM كبديل، ثم ينزّل الملف. لم نصدّر نسخة نهائية افتراضيًا؛ المعاينة متاحة للمراجعة أولًا.

## المحتوى

1. الدعوة، اختيار Google أو الإيميل، وكود التأكيد.
2. خطوات بيانات اللاعب الأربع وفترة تجهيز الخطة.
3. الرئيسية، جدول الأسبوع، الجاهزية والمية.
4. الحركة، الوزن والعدات، تسجيل المجموعة، الراحة، الفورم وتقييم الجلسة.
5. الوجبات، البدائل، تسجيل الأكل والمكملات إن كانت معيّنة.
6. التطور، تحديث الأسبوع، InBody وسجل التمارين.
7. الرتبة الدائمة وسباق التاج الشهري.
8. الكابتن، الاشتراك، الإعدادات والإشعارات.
9. إضافة التطبيق للشاشة الرئيسية وحدود العمل من غير نت.

## مصدر اللقطات وحدودها

- اللقطات من حزمة ديمو المشروع المحفوظة بتاريخ 6 نوفمبر 2026، ببيانات تجريبية. النسخ داخل `assets/` لا تعدّل الأصول.
- تحريك الصور مونتاج، وليس تسجيلًا حيًا للضغط أو الحفظ أو المزامنة. الصور الثابتة قد تتضمن شريط تنقل مثبتًا في منتصف الصفحة الطويلة؛ حافظنا على الواجهة كما التُقطت.
- مشاهد الدعوة والتسجيل والإعداد والإنهاء والجاهزية والمكملات والرتب والإشعارات والتثبيت والحفظ المحلي **شروحات توضيحية** ومكتوب عليها ذلك، وليست لقطات لتلك الشاشات.
- النص مبني على ملفات الواجهة الحالية؛ تستخدم الرتب الحالية سباق التاج الشهري، وليس تصور Unique السابق.
- محاولة الالتقاط المحلي الجديدة فشلت بـ`ERR_TOO_MANY_REDIRECTS` على `/demo`؛ التفاصيل في `review/capture.json`. لم نغيّر التطبيق لمعالجة ذلك.
- لم نُنشئ دعوات أو نستخدم أكواد تحقق أو حسابات عملاء حقيقيين.

## الملفات

| الملف | المسؤولية |
|---|---|
| `messages.ts` | كل النصوص المصرية، المشاهد، الفصول وتوقيتاتها |
| `timeline.mjs` | حساب الوقت والمشهد والكابشن الحالي |
| `timeline.test.mjs` | اختبارات حدود الوقت والتنقل وتوقيت القراءة |
| `draw.mjs` | رسم النصوص العربية ولفّ السطور |
| `illustrations.mjs` | الشروحات التوضيحية المعلّمة |
| `scenes.mjs` | تكوين مشاهد الفيديو وقص وتمرير لقطات الديمو |
| `player.mjs` | التشغيل والتنقل والتصدير الصامت |
| `index.html` و`styles.css` | صفحة المعاينة المتجاوبة |
| `server.mjs` | سيرفر محلي يقرأ الخطوط والهوية من المشروع |
| `capture.mjs` | محاولة التقاط الديمو، مع بديل اللقطات الموجودة |
| `verify.mjs` | فحص كل الكابشنات والفصول والتشغيل والعرض على الموبايل |
| `assets/` | لقطات الديمو المنسوخة |
| `review/` | صور المراجعة، لوحة المشاهد وتقارير التحقق |

## التحقق

مع تشغيل سيرفر المعاينة:

```text
node --test docs/creative/player-guide/timeline.test.mjs
node docs/creative/player-guide/verify.mjs
npm run check
npm run build
```

لا توجد dependencies جديدة أو تعديلات مقصودة على التطبيق أو قاعدة البيانات.
