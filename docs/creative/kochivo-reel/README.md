# KOCHIVO — يومك ككابتن

نسخة معاينة إعلانية مدتها 31.2 ثانية، بنسبة 9:16 ودقة 1080×1920.

## الملفات

- `kochivo-day.mp4`: الفيديو بالموسيقى والمؤثرات الأصلية. لا يحتوي على تعليق صوتي.
- `index.html`: مشغّل المعاينة مع التحكم بالصوت والتنقل بين المشاهد.
- `messages.ts`: النصوص المصرية، مع فصلها عن الرسم والحركة.
- `timeline.mjs`: توقيتات المشاهد وحساب موضع التشغيل.
- `scenes.mjs` و`draw.mjs`: الحركة والتكوين والرسم.
- `audio.mjs`: موسيقى ومؤثرات مولدة محليًا، من غير أصول صوتية خارجية.
- `assets/`: قصّات مشتقة من لقطات التطبيق. الأصول الأصلية لم تتغير.
- `review/`: صور المراجعة وتقرير التحقق من ملف الفيديو.

## المعاينة وإعادة التصدير

من جذر المشروع، شغّل `node docs/creative/kochivo-reel/server.mjs`، ثم افتح:

http://127.0.0.1:4318

لإعادة التصدير باستخدام Playwright الموجود وMicrosoft Edge:

```text
node docs/creative/kochivo-reel/render.mjs
node docs/creative/kochivo-reel/verify.mjs
node --test docs/creative/kochivo-reel/timeline.test.mjs docs/creative/kochivo-reel/data-url.test.mjs
```

الكود يستخدم أدوات المشروع الموجودة وواجهات المتصفح الأصلية. لا يحتاج إلى Remotion أو إضافة dependencies.

## حدود المعاينة

حركة الواجهات عبارة عن قصّ وتقريب وتمرير مونتاجي لصور ديمو ثابتة، وليست تسجيلًا حيًا للتفاعل أو المزامنة. أرقام التطور بيانات تجريبية ولا تمثل وعدًا بنتيجة. الفيديو يستخدم واجهات Kochivo الأصلية وشعاره وخطوطه وألوانه. لا يحتوي على صور أو صوت مقتبس من فيديو GymRate. الرابط النهائي للديمو غير مضاف؛ الدعوة الختامية هي «جرّب الديمو».
